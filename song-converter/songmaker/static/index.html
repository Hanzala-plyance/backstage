Play on drums.

Checking the exported drum track…
  1. Switch your player to drums.

    In Clone Hero, press Start (Enter on the default keyboard layout) to open your profile. Set Controller → Drums.

  2. Choose the right drum mode.

    Select Drums for regular pads, or Pro Drums if you use cymbals. A guitar profile only offers guitar instruments.

  3. Import the full-band export.

    Unzip the latest download into Songs, replace the older copy, and run Settings → General → Scan Songs. Then select your song and difficulty.

No separate drums.ogg is needed: the complete song audio is in song.ogg. The playable drum notes are in notes.mid.
